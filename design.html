Message flow

A sent message is stored in three structures at once. Undo pops the latest message ID from the stack and removes that message from the queue, if it is still pending, and from the chat history.

Message queueLinked list, FIFOEnqueue at rear. Incoming messages are dequeued from the front, oldest first.
Chat historyDoubly linked listAppend at tail. Read forward (next) or backward (prev).
Undo stackLinked list, LIFOPush the message ID. Undo pops the top ID.
