Student Communication System

A menu-driven C program that works as a small messaging tool for students. It uses eleven data structures, and each feature gets the structure that suits it best.

Abstract

A user can register students, search and sort their records, send messages and read them in the order they arrived, view the chat history, undo a message, form study groups, connect students with each other, find the shortest connection path and see the most urgent notification first. The aim is to show how the data structures taught in IT23302 work together in one real application. The program compiles with no warning and was tested through every menu option.

Introduction

Different tasks in a messaging system need different data structures. Messages must be delivered in the order they were sent, the latest message must be the first one undone, important notices must come before ordinary ones, and students form a network of connections. Using a single array for all of these would make some tasks slow or clumsy. This project matches each task with the structure that handles it best.

Objectives

  • Store and manage student records using structures and a singly linked list.
  • Search by linear search, binary search and a binary search tree; sort using selection, insertion and radix sort.
  • Deliver messages with a queue, keep the chat history in a doubly linked list and undo with a stack.
  • Rotate the speaking turn of a study group with a circular linked list.
  • Store connections in a graph, traverse with BFS and DFS and find the shortest connection path.
  • Show the most urgent notification first with a max heap, and find a student quickly with a hash table using linear probing.
